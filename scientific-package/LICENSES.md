# Component licence and authorization map

| Component | Licence or treatment | Packaging authorization |
|---|---|---|
| Current original manuscript, claims, metadata, diagrams, and original research data | CC0-1.0 | Authorized for redistribution |
| Current original code, tests, replay tools, and build scripts | MIT | Authorized for redistribution |
| Cited publications and downloaded arXiv source archives | Upstream terms | Reference-only; hashes and citations may be distributed, source bytes are not included |
| DOI, arXiv, GitHub, and public-web metadata | Upstream terms | Reference-only; minimal factual metadata may be distributed |
| Cyclicity Support-Fusion Atlas v0.7.0-candidate | Its packaged CC0/MIT/component map | Used as an externally pinned replay input; not relicensed here |
| Internal or supplied review reports | NOASSERTION unless the individual file states otherwise | Retained as review provenance; not part of the scientific claim target |
| Pandoc, TeX, Python, SymPy, qpdf, and other build/runtime software | Respective upstream terms | Not vendored by this candidate package |

The public research package must contain only files named by its explicit
manifest and top-level allowlist. A public URL or successful download is not,
by itself, authority to redistribute the downloaded bytes.

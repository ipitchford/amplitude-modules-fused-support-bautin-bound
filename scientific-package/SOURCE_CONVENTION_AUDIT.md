# Source-convention audit for the Bautin-index comparison

## Frozen source

- Source: Bravo, Mardesic, Novikov and Pontigo-Herrera,
  *Infinitesimal and tangential 16-th Hilbert problem on zero-cycles*,
  arXiv:2312.03081v1.
- Frozen source SHA-256:
  `1fd6911d99c076200e4ded8cb8c48322852cefe4024940547693e06f4b3eda40`.
- Source record: `arxiv-2312.03081v1-source` in
  `SOURCE_PROVENANCE.json`.
- Inspected locator: TeX source lines 1971-1977 in the frozen v1 response.

## What the source specifies

The source expands the displacement function in powers of the deformation
parameter, calls the coefficients `M_i`, observes Noetherian stabilization of
the ascending sequence of ideals generated by those coefficients for fixed
degree, and calls the stabilization index `b(m)`. It asks for a bound when the
phase and deformation degrees are at most `m`.

## What the source does not specify at that locator

The problem statement does not identify:

- the ambient coefficient ring in which the displayed ideals live;
- whether the multivalued functions are first expanded in a local `t`-series;
- whether coefficients are aggregated over all determinations;
- whether an ideal is contracted from a function ring to a polynomial
  parameter ring;
- whether localization, radicalization, or base-point specialization is
  intended; or
- the order of any such operations.

## Consequence for this candidate

The manuscript's unconditional object is the ordinary parameter-content,
equivalently local Taylor-coefficient, ideal in the explicitly defined
polynomial parameter ring. Its theorem is therefore stated as
`B_infinity = B_{d-1}` and `b_coeff(m) <= m-1` for that convention.

Identification of this `b_coeff(m)` with the source's `b(m)` remains
conditional on the source intending the same ambient-ring and coefficient-
extraction convention. The frozen source does not, by itself, establish that
semantic bridge. This audit therefore supports a standalone coefficient-Bautin
theorem candidate and forbids an unconditional statement that the published
problem has been solved.

This is a source-definition audit, not independent theorem validation or a
priority determination.
